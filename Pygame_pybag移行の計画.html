03 Pygame 版への移植方針

3-1. ウィンドウ・描画系

PyxelPygame備考
pyxel.init(w, h)pygame.display.set_mode((w,h))同じ 256×256 でOK
cls(color)screen.fill(palette[color])Pyxel 色番号 → RGB 変換テーブルが必要
rect(x,y,w,h,c)pygame.draw.rect(screen, color, rect)塗りつぶし矩形
rectb(x,y,w,h,c)pygame.draw.rect(..., width=1)枠線矩形
text(x,y,s,c,font=)font.render(s, True, color) + blit日本語フォントを指定

3-2. 入力系

PyxelPygame備考
btn(KEY)pygame.key.get_pressed()[K]押下中判定
btnp(KEY)btn + 前フレーム状態比較自前でトリガー管理が必要
MOUSE_BUTTON_LEFTpygame.mouse.get_pressed()[0]左クリック
GAMEPAD1_*pygame.joystickジョイスティックモジュールで代替
注意： Pyxel の btnp（1回だけ検出）は Pygame に直接相当する関数がない。前フレームのキー状態を保持して、not prev and curr で判定する簡易トリガー管理クラスを自作する必要がある。

3-3. フォント系

PyxelPygame備考
pyxel.Font(path, size)pygame.font.Font(path, size)API がほぼ一致
font.text_width(s)font.size(s)[0]文字列幅の取得
pyxel.FONT_WIDTHfont.size("あ")[0]固定幅フォントなら等価

3-4. サウンド系

PyxelPygame備考
pyxel.Sound()pygame.mixer.Sound(buffer)Pyxel のノート記法は自前で変換
pyxel.play(ch, snd)sound.play()チャンネル概念は mixer 側で管理
Pyxel の set("c3", "n", "2", "n", 1) のようなノート指定は Pygame にはない。短いビープ音を生成する簡易ジェネレータを自作するか、あらかじめ WAV ファイルを用意して読み込む方式に切り替えるのが現実的。

3-5. メインループ

Pyxel の pyxel.run(update, draw) はフレームレート制御付きのゲームループを自動で実行する。Pygame 版では自前で以下のループを実装する。

clock = pygame.time.Clock()
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    update()
    draw()
    pygame.display.flip()
    clock.tick(60)

04 pygbag 対応ポイント

4-1. メインループを async にする

pygbag ではメインループを asyncio ベースに書き換える必要がある。pygame.run の代わりに以下の構造にする。

import asyncio

async def main():
    # 初期化
    while True:
        for event in pygame.event.get():
            ...
        update()
        draw()
        pygame.display.flip()
        await asyncio.sleep(0)  # 必須

asyncio.run(main())
重要： await asyncio.sleep(0) をループ内に入れないとブラウザがフリーズする。これは pygbag の鉄則。

4-2. アセットの読み込み方法

pygbag ではファイルシステムへの直接アクセスが制限される。フォントファイルやテキストファイルは以下のいずれかの方法でう。

  • 方法A： ビルド時に --assets オプションでファイルを同梱し、実行時は pyodide.http または pygbag のプリロード機構で読み込む
  • 方法B： フォントとテキストを Python コード内に Base64 埋め込みして実行時に一時ファイルとして書き出す
  • 方法C： フォントをシステムフォントに置き換え、テキストはサンプルテキストをコード内に持つ（デモ用途）

4-3. サウンドの扱い

pygbag 環境では pygame.mixer の挙動に制限が出ることがある。対応方針は以下の通り。

  • タイピング音は「あれば再生、なければ無音」のフォールバック設計にする
  • ビープ音生成は pygame.sndarray で numpy 配列から作成する方式が安定しやすい
  • サウンド周りのコードは try/except で囲み、失敗してもゲームが止まらないようにする

4-4. ビルドと配布

pip install pygbag
pygbag --assets PixelMplus10-Regular.ttf,PixelMplus12-Regular.ttf,aozora_416.txt main.py

ビルド後、build/web/ 以下に出力されるファイル群を静的ホスティング（GitHub Pages など）に置くと、URL からブラウザで実行できる。

06 リスクと対策

リスク影響度対策
pygbag でフォントファイルが読めない 高 Base64 埋め込み方式のフォールバックを用意する
日本語フォントが大きくて読み込みが遅い 中 サブセット化した軽量フォントを用意する
ブラウザでのキー入力が奪われる 中 Space / Arrow / Enter はブラウザショートカットと競合するため、canvas フォーカス管理を確認
サウンドが再生されない 低 サウンドは必須ではないので無効化でも動作する設計にする
Pygame の text_width が日本語でずれる 中 PixelMplus は等幅前提なので、半角・全角の混在を考慮した幅計算を確認
